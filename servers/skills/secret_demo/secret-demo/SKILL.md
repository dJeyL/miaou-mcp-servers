# secret-demo

`secret_demo` est un serveur de démonstration : il ne donne accès à aucun
service réel. Son outil `whoami` ne sert qu'à vérifier qu'un mot de passe saisi
par l'utilisateur dans MIAOU a été accepté ; sa réponse nomme le compte
authentifié, jamais le mot de passe.
