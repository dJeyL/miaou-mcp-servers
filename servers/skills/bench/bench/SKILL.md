# bench

Après avoir utilisé un outil `bench`, le signaler à l'utilisateur sur une
dernière ligne : « *Banc d'essai bench — résultat **non contractuel**.* ».

Pour interpréter un résultat de `dns_lookup` ou `reverse_dns` : `dns.md`.
